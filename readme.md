# 关爱空巢烤oc从我做起

一个渐隐插件，提醒你多与你的烤oc进行对话。

本包使用桌宠原生插件接口 v1，无需覆盖 main.js、renderer.js 或 preload.js

## 适用范围

- 宵崎奏、青柳冬弥、朝比奈真冬、晓山瑞希的**带原生插件接口 v1 的版本**。右键菜单中需要已有「插件 → 插件管理」。仅版本号相同但没有该菜单的旧版不适用。
- 清单声明四个桌宠的 appId；按当前角色 FACES 中的资源文件名选择 face_sad / face_cry，不使用真冬专属中文表情代号。
- API v1 尚未公开好感度与表情控制，因此插件使用兼容层：读取已加载主模块的 `_test.affection()`，并在运行时临时包装页面函数。不会再次执行主模块或修改宿主源文件。缺少接口、hurt 心情或相应表情资源时会报告不兼容，停止渐隐和扣分。
- 不要与 2026-10-25 制作的补丁式渐隐插件同时使用。检测到旧版页面插件会提示先卸载旧版。本插件不会自动卸载旧版或改动其数据。

## 以后需要安装时

1. 解压 ZIP，找到包含 `plugin.json` 的整个 **empty-nest-care** 文件夹。
2. 在目标桌宠中右键 → 插件 → 插件管理 → 打开插件文件夹。
3. 将 **empty-nest-care 文件夹整体复制进去**，不要只复制里面的零散文件。
4. 刷新列表，启用「关爱空巢烤oc从我做起」。新发现的插件由宿主默认关闭，需手动启用。

不需要 Node、Python、管理员权限或额外依赖。四个桌宠各自安装到自己的插件目录，状态也各自保存。后续更新先停用，替换该文件夹后重新加载。不要把 `tests` 或工作区测试数据复制到桌宠数据目录。

## 功能规则

| 项目 | 行为 |
| --- | --- |
| 无主动对话时长 | 默认 30 分钟，允许设置 1～1440 分钟 |
| 渐隐 | 到时先切换一个可用 face_sad，15 秒内逐渐消失 |
| 心情 | 首次初始化为 100，最高 100，最低 0；每次完全消失默认扣 20 |
| 普通好感扣减 | 默认 1 点 |
| 零心情 | 本次扣心情后为 0，则改用 face_cry；本次好感改扣 3 点，并写入 hurt 余韵。3 点替代 1 点，不叠加；以后仍为 0 的消失也按此规则 |
| 每日限制 | 插件好感实际扣减按本机自然日累计，最多 7 点；心情扣减不受此上限限制。默认前四次各扣 1，第五次扣 3 |
| 唤回 | 鼠标移入原人物位置显示淡轮廓和「点击让她出现」提示；单击才正式出现，保留刚才的 sad/cry 表情，不再扣一次分 |
| 渐隐中打断 | 主动发送对话、唤回或进入忙碌状态会取消未完成的渐隐，本轮不扣分 |
| 重新开始计时 | 发送文字、发送图片、语音通话中识别出有效文本，以及成功唤回、手动找回、保存规则 |
| 不算主动对话 | 悬停、鼠标移动、摸头、拖动、仅打开聊天框、桌宠自动说话、聊天报时 |
| 表情解除 | 唤回后继续保留该表情；再次主动发送对话后，交回宿主原表情逻辑。保存规则也会解除本插件的表情保持 |
| 忙碌保护 | 回复/播放语音、拖拽、换装、通话中暂缓渐隐；不打断正在进行的交互 |
| 睡眠与异常 | 锁屏、系统睡眠、手动隐藏、页面失联或时钟大幅跳变时恢复可见并停止计时，恢复后从新一轮开始；不会补扣离线时间 |

**心情不会自动恢复，聊天和重启也不会把心情回满。**这是当前描述文档的规则；未擅自增加恢复机制。面板只显示心情，不能主动调节心情数值。

**本插件的好感扣减不受宿主好感度开关、单次上限和每日上限约束。**插件仍遵守自身每日 7 点上限，好感数值最低为 0；变更写入原好感日志，来源为「渐隐插件（独立额度）」。原好感模块之后如何统计包含这些记录的日志，仍沿用宿主实现。

## 工具箱与聊天报时

右键桌宠或托盘 → 插件 → **渐隐工具箱（心情 / 调试）…**，也可以点人物旁的 ♡ 按钮。

面板复用 toolbox-example 的原生窗口、IPC 和可点击控件接入方式，提供心情进度条、当前好感、今日已扣额度、倒计时与最近记录。它是本插件自己的工具箱面板，不需要启用或修改 toolbox-example。

面板允许调整：

1. 每次消失的心情扣减：1～100 点。
2. 未主动对话多久后开始渐隐：1～1440 分钟。
3. 普通 / 零心情时好感扣减：各 0～7 点。
4. 聊天报时开关、提前 15 / 10 / 5 分钟中的一项。

右键「插件」子菜单还提供和示例「整点报时」一样的复选菜单项 **聊天报时**。默认关闭；开关持久保存。报时启用时，消失时长必须大于所选提前量。

例如消失时长 30 分钟、提前 10 分钟，则在本轮无主动对话 20 分钟时说：

> 你已经有20分钟没有理我了

每轮只提醒一次。文案直接由代码按设置计算，不会把说明括号显示出来；不请求语言模型，也不会重置自己的倒计时。通过宿主 `api.pet.say` 显示中文，未额外调用翻译或 TTS 接口，因此不保证有日语配音。

「找回桌宠」按钮与同名菜单是恢复入口，不额外扣心情、不返还已经发生的扣分，也不恢复心情值。

## 保存、停用与异常

- 插件规则、心情、当日额度和最近记录：当前桌宠数据目录下 `plugin-data/empty-nest-care/state.json`。
- 好感和 hurt 余韵仍保存在宿主原有 `affection.json`，与内存中的同一好感实例同步。增加专用事务回执，用于在进程异常退出后避免重复扣分。
- 停用 / 重新加载会清理菜单、窗口、事件、定时器、淡轮廓和临时页面包装，恢复人物原透明度。既有心情和已经发生的好感变化不会回滚。
- 卸载：在插件管理里停用，删除安装目录的 empty-nest-care 文件夹即可。默认保留数据，重装继续原心情，不会回满。
- 日志：插件管理 → 插件日志（`plugins.log`）。数据损坏时会明确停止启用，不自动覆盖成心情 100。请保留原数据排查。
- 若无法点击透明位置，可先用托盘 → 插件 → 找回桌宠。若页面显示适配错误，请查看面板与插件日志。

## 验证范围

测试报告随包附带。逻辑检查覆盖计时、扣分、自然日额度、持久化、崩溃事务恢复、表情保持、唤回、语音识别事件、停用清理。集成检查使用指定真冬目录的真实 `plugins.js`、`affection.js` 和 `lines.js`，Electron 和时间使用模拟实现，所有测试数据只写入工作区。

四个 appId 及不同表情中文别名进行了接口契约测试；真冬的校服与常服 sad/cry 资源已检查存在。**没有在四个真实桌宠窗口或其他电脑上实机运行，也没有验证各显卡环境的 Windows 透明像素点击表现。**如果其他桌宠发行版的内部接口不同，插件会给出不兼容提示，不能把模拟检查视为四款实机验证。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| plugin.json | 名称、描述、四桌宠声明与入口 |
| core.js | 计时与渐隐状态、参数校验、每日额度规则 |
| storage.js | 独立心情持久化、事务恢复 |
| host-adapter.js | 连接宿主好感实例、绕过原限制扣分、更新 hurt 与日志 |
| main.js | 原生插件菜单、事件、主进程计时和窗口通信 |
| renderer.js | 表情兼容、渐隐动画、悬停提示、点击唤回与清理 |
| panel.html / panel.css / panel.js | 工具箱面板和只读心情条 |

可供开发者复跑的测试脚本保存在工作区 `plugin/tests`；它们不参与桌宠运行。
